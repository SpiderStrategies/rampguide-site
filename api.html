01Programmatic accessthe trust center, for programs

Everything a person sees, a program can fetch.

A provider's trust center on RampGuide serves its FedRAMP Certification Package to people in a browser and to programs over HTTPS: the same index, the same files, the same hashes. FedRAMP is the Federal Risk and Authorization Management Program, and its 2026 rules ask a provider to document this programmatic access. The machine-readable form of everything on this page is the service's own OpenAPI document at trust.rampguide.com/v1/openapi.json; the routes and the rules below are read from it as you open this page, so the two can never disagree.

02Fetch a file and check itthe key is a party key, minted on your access page
your shellACME Corp, fictional
$ export KEY=rgt_live_…            # a party key, minted on your access page
$ curl -s -H "Authorization: Bearer $KEY" \
    https://trust.rampguide.com/v1/t/acme/index.json | jq '.files[] | {path, tier, sha256}'
$ curl -sL -H "Authorization: Bearer $KEY" -o sdr.json \
    https://trust.rampguide.com/v1/t/acme/files/fedramp/sdr.json
$ shasum -a 256 sdr.json
7396608116c9…  sdr.json          # the sha256 index.json promised

A file request answers 302 to a link that works for sixty seconds, with a JSON body carrying the file's SHA-256 hash, its size and its tier. The same file is available inline at /raw/ for viewers. Either answer is the logged access.

03Three ways to authenticatepeople, systems, the provider's pipeline
  • Session cookieFor people. A passkey sign-in at the trust center sets it, the browser sends it on its own, and it lasts one hour idle and twelve hours in all.
  • Party API keyFor an agency's or an assessor's own systems. Minted by your team lead on your access page, scoped to one trust center and one tier, expiring within a year, every use logged; sent as Authorization: Bearer rgt_live_….
  • Publish keyFor the provider's build pipeline only. It can publish and nothing else, and the trust center checks every uploaded file against the manifest.
